# Contribution guidelines

Public contributions are welcome. No real subscriptions, tokens, device identifiers or production backups may be committed. Use TEST-NET addresses and fake nodes in tests. Keep new features isolated from real HOS devices and include rollback tests for any configuration writes.

For upstream HOS store integration, first deliver a fully verified ARM64 image, native resource files, and a clean-device installation result. Submit a separate PR to the application definition repository only after meeting that gate.
